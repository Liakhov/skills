# Conventions

- Keep skills in `skills/<name>/SKILL.md`; the folder and frontmatter names must match.
- Write concise instructions and specific descriptions of when to use each skill.
- Keep supporting files inside the skill directory. Add them only when needed.
- Keep explicit-only settings consistent between `SKILL.md` and `agents/openai.yaml`.
- Update the README skill list when adding or renaming skills.
- Check metadata and local links; run changed scripts and try behavioral changes.
- Preserve unrelated edits. Commit only when requested.
